# Дзеркало записів сайту Української громади

Автоматична копія останніх 30 записів [ukrainska-gromada.gov.ua](https://ukrainska-gromada.gov.ua) (WordPress REST API) і їхніх головних зображень.
Потрібна для [ukrainka.top](https://ukrainka.top): сервер автозбирання не має прямого доступу до сайту громади.

- `posts.json` — відповідь `/wp-json/wp/v2/posts` як є, адреси зображень вказують на `img/`
- `meta.json` — коли зібрано і який запис найновіший
- оновлюється що 30 хв скриптом `update.sh` з машини з українським IP (з-за кордону сайт громади недоступний), коміт — лише якщо щось змінилося

Усі матеріали належать Українській міській раді; першоджерело — посилання `link` у кожному записі.
